\section{Theoretical Background}
\label{sec:fund}

\textbf{Sparse View Datasets.} In this work, this term refers to image datasets lacking redundancy or camera pose variability for a given object. Fields like histology, holotomography, and fluorescence confocal microscopy exemplify this challenge, where multi-view acquisition is physically limited, biologically invasive, and inherently sparse \cite{ijms24076747}.

\textbf{Neural Radiance Fields (NeRF).} NeRFs utilize Multilayer Perceptrons (MLPs) to approximate a continuous 5D function \cite{mildenhall2020nerfrepresentingscenesneural}. This function takes a spatial position $\mathbf{x} = (x, y, z)$ and a viewing direction $\mathbf{d} = (\theta, \phi)$ as inputs, outputting the volumetric density $\sigma(\mathbf{x})$ and associated color $\mathbf{c} = (r, g, b)$:

$$
F_\theta : F_\theta\prime \circ \gamma(\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c}),\ \ \sigma \in \mathbb{R}_{\geq0},\ \mathbf{c} \in [0, 1]^3
$$
where $\theta$ represents the neural network weights, $F_\theta'$ is the original MLP, and $\gamma$ is a positional encoder.

\textbf{Scene Representations.} Subsequent works introduced hybrid representations that decouple the spatial structure from the neural network by replacing Fourier positional encoding with hash encoding. Instant-NGP \cite{muller2022} proposes a multiscale hash table encoding that efficiently maps spatial coordinates to feature vectors, drastically reducing per-scene optimization time. Nerfacto \cite{Tancik2023} extends this by combining proven heuristics from the literature, focusing on balancing visual quality and real-time rendering performance.

\textbf{Volumetric Rendering.} For a given neural radiance field $F_\theta$, the expected color of a pixel is computed via volumetric rendering. For a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ with depth bounds $(t_n, t_f)$, the resulting color is given by the integral:
$$\hat{C}(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(\mathbf{r}(t)) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) \, dt$$
where $T(t) = \exp\left(-\int_{t_n}^t \sigma(\mathbf{r}(s)) \, ds\right)$ denotes the accumulated transmittance, representing the probability that the ray does not hit any obstructive particle up to depth $t$. In practice, this integral is numerically approximated via alpha compositing over discrete samples along each ray during training.

\textbf{Feature Extractor.} The feature extractor encodes input images into representations that condition the neural network. PixelNeRF \cite{yu2021pixelnerfneuralradiancefields} uses a pre-trained ResNet to extract per-image feature maps; given a 3D point, its 2D projection onto the input views retrieves the corresponding spatial features, which are aggregated and passed to the radiance MLP. GNT (Generalizable NeRF Transformer) \cite{t2023attentionnerfneeds} replaces: (i) the feature extractor with a vision transformer to capture more global object features; and (ii) the radiance MLP with a cross-attention transformer that samples points along the ray and aggregates multi-view information, eliminating the explicit volume function dependency.

\textbf{Few-Shot vs. Per-Scene NeRFs.} To reduce the need for dense multi-view training data, few-shot NeRFs generalize and synthesize novel views from sparse inputs by applying diverse concepts to the aforementioned NeRF components. These contrast sharply with per-scene methods. While per-scene models (e.g., Instant-NGP) optimize isolated data structures and suffer severe geometric degradation under view scarcity, generalizable few-shot architectures incorporate structural priors learned from large datasets. To maximize visual fidelity in generalizable models, Test-Time Adaptation (TTA) is frequently employed. Instead of purely zero-shot inference, TTA fine-tunes the network weights using the sparse views of the novel scene. This rapid optimization reduces the domain gap, though it introduces the risk of representational collapse (catastrophic forgetting) if the network overfits to the sparse inputs.
